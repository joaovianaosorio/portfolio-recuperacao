## 📌 Sobre o Projeto

Este projeto consiste em uma aplicação web estática desenvolvida como **Portfólio Pessoal e Acadêmico**. O objetivo principal é centralizar a trajetória acadêmica, competências técnicas, histórico de projetos práticos e meios de contato em uma interface moderna, intuitiva e totalmente responsiva.

## ✨ Resumo das Funcionalidades

- **Apresentação Hero:** Apresentação profissional com ações rápidas de navegação.
- **Sobre Mim & Hobbies:** Seção detalhada sobre trajetória acadêmica e interesses pessoais (assistir MMA, futebol, tocar violão e estudar sobre tecnologia).
- **Galeria de Projetos:** Cards interativos para exibição dos projetos em destaque (Simulador de Juros, TCC ETEC, entre outros) com links diretos para repositórios e simulações.
- **Habilidades & Competências:** Mapeamento visual de linguagens e ferramentas (C, JavaScript, HTML, CSS, Git).
- **Download do Currículo:** Botão com atalho direto para download do currículo atualizado em formato PDF.
- **Design Responsivo & Mobile First:** Adaptação completa de layout e menu interativo para dispositivos móveis, tablets e desktops.
